# Radius SDK React Hooks

The Radius SDK provides a comprehensive set of React hooks for interacting with the Radius blockchain and ERC20 tokens. Built on top of wagmi v3, these hooks offer a seamless developer experience with TypeScript support and React best practices.

## Installation

Install the Radius SDK along with its required peer dependencies:

```bash
pnpm add @radiustechsystems/sdk wagmi viem @tanstack/react-query
```

Or using npm:

```bash
npm install @radiustechsystems/sdk wagmi viem @tanstack/react-query
```

Or using yarn:

```bash
yarn add @radiustechsystems/sdk wagmi viem @tanstack/react-query
```

## Setup

### RadiusProvider

The `RadiusProvider` component is the entry point for using Radius SDK hooks. It sets up the necessary providers (wagmi, React Query) and Radius context for your application.

Wrap your application or a section of it with the `RadiusProvider`:

```tsx
import { RadiusProvider } from '@radiustechsystems/sdk/react';
import { radiusTestnet } from '@radiustechsystems/sdk/react';

export function App() {
  return (
    <RadiusProvider chain={radiusTestnet}>
      <YourApp />
    </RadiusProvider>
  );
}
```

#### RadiusProvider Props

| Name | Type | Default | Description |
|------|------|---------|-------------|
| chain | `Chain` | `radiusTestnet` | The blockchain chain configuration |
| children | `ReactNode` | Required | Child components that will have access to Radius hooks |
| queryClient | `QueryClient` | `undefined` | Optional custom React Query client instance. If not provided, a new instance is created |

#### Example with Custom QueryClient

```tsx
import { RadiusProvider } from '@radiustechsystems/sdk/react';
import { radiusTestnet } from '@radiustechsystems/sdk/react';
import { QueryClient } from '@tanstack/react-query';

const queryClient = new QueryClient({
  defaultOptions: {
    queries: {
      staleTime: 1000 * 60 * 5, // 5 minutes
    },
  },
});

export function App() {
  return (
    <RadiusProvider chain={radiusTestnet} queryClient={queryClient}>
      <YourApp />
    </RadiusProvider>
  );
}
```

## Hooks Reference

### useRadiusContext

Access the Radius context to retrieve the configured chain and other context values.

**Must be used within a RadiusProvider component.**

#### Returns

| Property | Type | Description |
|----------|------|-------------|
| chain | `Chain` | The currently configured Viem Chain object |

#### Example

```tsx
import { useRadiusContext } from '@radiustechsystems/sdk/react';

function ChainInfo() {
  const { chain } = useRadiusContext();

  return (
    <div>
      <p>Chain: {chain.name}</p>
      <p>Chain ID: {chain.id}</p>
      <p>RPC URL: {chain.rpcUrls.default.http[0]}</p>
    </div>
  );
}
```

### useRadiusBalance

Fetches the native token (USD) balance for an address on the Radius blockchain. Uses wagmi's `useBalance` hook under the hood.

#### Parameters

| Name | Type | Required | Description |
|------|------|----------|-------------|
| address | `Address \| undefined` | No | The blockchain address to check the balance for. If not provided, uses the connected wallet address |

#### Returns

| Property | Type | Description |
|----------|------|-------------|
| data | `BalanceResult \| undefined` | The balance result containing `value` (in wei) and `decimals` |
| data.value | `bigint` | The balance amount in wei |
| data.decimals | `number` | Number of decimals for the token (always 18 for native token) |
| data.symbol | `string` | The token symbol (e.g., "USD") |
| data.formatted | `string` | The formatted balance as a decimal string |
| isLoading | `boolean` | Whether the balance is currently being fetched |
| isError | `boolean` | Whether an error occurred while fetching the balance |
| error | `Error \| null` | The error object if an error occurred |
| refetch | `() => Promise<void>` | Function to manually refetch the balance |

#### Example - Fetch Connected Account Balance

```tsx
import { useRadiusBalance } from '@radiustechsystems/sdk/react';

function BalanceDisplay() {
  const { data, isLoading, isError } = useRadiusBalance();

  if (isLoading) return <div>Loading balance...</div>;
  if (isError) return <div>Error loading balance</div>;

  return (
    <div>
      <p>Balance: {data?.formatted} {data?.symbol}</p>
    </div>
  );
}
```

#### Example - Fetch Specific Address Balance

```tsx
import { useRadiusBalance } from '@radiustechsystems/sdk/react';

function AddressBalance({ address }: { address: string }) {
  const { data, isLoading } = useRadiusBalance({ address });

  if (isLoading) return <div>Loading...</div>;

  return <div>Balance: {data?.formatted} {data?.symbol}</div>;
}
```

### useRadiusSend

Sends native tokens (USD) to a recipient address. Handles transaction submission, confirmation waiting, and provides state management.

#### Parameters

None. Call the `send` function with the transaction parameters.

#### Returns

| Property | Type | Description |
|----------|------|-------------|
| hash | `Hash \| undefined` | The transaction hash once the transaction is submitted |
| receipt | `TransactionReceipt \| undefined` | The transaction receipt once the transaction is confirmed |
| error | `Error \| null` | Any error that occurred during the transaction |
| isPending | `boolean` | Whether the transaction is pending submission/confirmation |
| isConfirming | `boolean` | Whether the transaction is being confirmed on the blockchain |
| isConfirmed | `boolean` | Whether the transaction has been confirmed |
| send | `(params: UseRadiusSendParams) => void` | Function to initiate the transaction |
| reset | `() => void` | Function to reset the transaction state |

#### Send Parameters

The `send` function accepts an object with:

| Name | Type | Description |
|------|------|-------------|
| to | `Address` | The recipient address |
| value | `string \| bigint` | The amount to send. Can be a decimal string (e.g., "1.5") which will be parsed as ether, or a bigint in wei |

#### Example - Send with String Amount

```tsx
import { useRadiusSend } from '@radiustechsystems/sdk/react';
import { useState } from 'react';

function SendTransaction() {
  const { send, isPending, isConfirmed, hash, error } = useRadiusSend();
  const [recipient, setRecipient] = useState('');
  const [amount, setAmount] = useState('');

  const handleSend = () => {
    send({
      to: recipient,
      value: amount, // Can be "1.5" for 1.5 USD
    });
  };

  return (
    <div>
      <input
        placeholder="Recipient address"
        value={recipient}
        onChange={(e) => setRecipient(e.target.value)}
      />
      <input
        placeholder="Amount"
        value={amount}
        onChange={(e) => setAmount(e.target.value)}
      />
      <button onClick={handleSend} disabled={isPending}>
        {isPending ? 'Sending...' : 'Send'}
      </button>

      {error && <div>Error: {error.message}</div>}
      {hash && <div>Transaction: {hash}</div>}
      {isConfirmed && <div>Transaction confirmed!</div>}
    </div>
  );
}
```

#### Example - Send with BigInt Amount

```tsx
import { useRadiusSend } from '@radiustechsystems/sdk/react';
import { parseEther } from 'viem';

function SendBigIntExample() {
  const { send, isPending } = useRadiusSend();

  const handleSend = () => {
    send({
      to: '0x1234...5678',
      value: parseEther('2.5'), // 2.5 USD in wei
    });
  };

  return <button onClick={handleSend} disabled={isPending}>Send 2.5 USD</button>;
}
```

### useERC20Balance

Reads the balance of an ERC20 token for an address.

#### Parameters

| Name | Type | Required | Description |
|------|------|----------|-------------|
| token | `Address` | Yes | The ERC20 token contract address |
| address | `Address \| undefined` | No | The address to check the balance for. If not provided, uses the connected wallet address |

#### Returns

| Property | Type | Description |
|----------|------|-------------|
| data | `bigint \| undefined` | The token balance in the token's smallest unit (usually wei) |
| isLoading | `boolean` | Whether the balance is currently being fetched |
| isError | `boolean` | Whether an error occurred |
| error | `Error \| null` | The error object if an error occurred |
| refetch | `() => Promise<void>` | Function to manually refetch the balance |

#### Example - Get Connected Account Token Balance

```tsx
import { useERC20Balance } from '@radiustechsystems/sdk/react';
import { useERC20Metadata } from '@radiustechsystems/sdk/react';
import { formatUnits } from 'viem';

function TokenBalance({ tokenAddress }: { tokenAddress: string }) {
  const { data: balance, isLoading } = useERC20Balance({
    token: tokenAddress,
  });

  const { decimals } = useERC20Metadata({
    token: tokenAddress,
  });

  if (isLoading) return <div>Loading...</div>;

  const formatted = balance && decimals
    ? formatUnits(balance, decimals)
    : '0';

  return <div>Token Balance: {formatted}</div>;
}
```

#### Example - Get Specific Address Token Balance

```tsx
import { useERC20Balance } from '@radiustechsystems/sdk/react';

function SpecificAddressBalance({
  tokenAddress,
  userAddress,
}: {
  tokenAddress: string;
  userAddress: string;
}) {
  const { data: balance } = useERC20Balance({
    token: tokenAddress,
    address: userAddress,
  });

  return <div>Balance: {balance?.toString() || '0'}</div>;
}
```

### useERC20Approve

Approves an ERC20 token for spending by a spender address. Commonly used to authorize contracts to transfer tokens on your behalf.

#### Parameters

| Name | Type | Required | Description |
|------|------|----------|-------------|
| token | `Address` | Yes | The ERC20 token contract address |

#### Returns

| Property | Type | Description |
|----------|------|-------------|
| hash | `Hash \| undefined` | The transaction hash once submitted |
| receipt | `TransactionReceipt \| undefined` | The transaction receipt once confirmed |
| error | `Error \| null` | Any error that occurred |
| isPending | `boolean` | Whether the transaction is pending |
| isConfirming | `boolean` | Whether the transaction is being confirmed |
| isConfirmed | `boolean` | Whether the transaction has been confirmed |
| approve | `(spender: Address, amount: bigint) => void` | Function to approve spending |
| reset | `() => void` | Function to reset the state |

#### Example - Approve Token for Contract

```tsx
import { useERC20Approve } from '@radiustechsystems/sdk/react';
import { parseUnits } from 'viem';
import { useState } from 'react';

function ApproveToken() {
  const [amount, setAmount] = useState('');
  const tokenAddress = '0x...'; // ERC20 token address
  const contractAddress = '0x...'; // Contract to approve

  const { approve, isPending, isConfirmed, error } = useERC20Approve({
    token: tokenAddress,

    const amountInWei = parseUnits(amount, decimals);
    approve(contractAddress, amountInWei);
  };

  return (
    <div>
      <input
        placeholder="Amount to approve"
        value={amount}
        onChange={(e) => setAmount(e.target.value)}
      />
      <button onClick={handleApprove} disabled={isPending}>
        {isPending ? 'Approving...' : 'Approve'}
      </button>

      {error && <div>Error: {error.message}</div>}
      {isConfirmed && <div>Approval successful!</div>}
    </div>
  );
}
```

#### Example - Approve Unlimited Amount


### useERC20Allowance

Reads the allowance of an ERC20 token - how much a spender is allowed to transfer on behalf of an owner.

#### Parameters

| Name | Type | Required | Description |
|------|------|----------|-------------|
| token | `Address` | Yes | The ERC20 token contract address |
| owner | `Address \| undefined` | No | The token owner address. If not provided, uses the connected wallet address |
| spender | `Address` | Yes | The address allowed to spend the tokens |

#### Returns

| Property | Type | Description |
|----------|------|-------------|
| data | `bigint \| undefined` | The allowance amount in the token's smallest unit |
| isLoading | `boolean` | Whether the allowance is being fetched |
| isError | `boolean` | Whether an error occurred |
| error | `Error \| null` | The error object if an error occurred |
| refetch | `() => Promise<void>` | Function to manually refetch the allowance |

#### Example - Check Allowance

```tsx
import { useERC20Allowance } from '@radiustechsystems/sdk/react';
import { formatUnits } from 'viem';

function AllowanceDisplay() {
  const tokenAddress = '0x...';
  const contractAddress = '0x...';

  const { data: allowance, isLoading } = useERC20Allowance({
    token: tokenAddress,
    spender: contractAddress,
  });

  if (isLoading) return <div>Loading allowance...</div>;

  return (
    <div>
      Allowance: {allowance ? formatUnits(allowance, 18) : '0'}
    </div>
  );
}
```

#### Example - Check If Approval Needed

```tsx
import { useERC20Allowance } from '@radiustechsystems/sdk/react';
import { useERC20Balance } from '@radiustechsystems/sdk/react';
import { parseUnits } from 'viem';

function ApprovalCheck({
  tokenAddress,
  contractAddress,
  requiredAmount,
  decimals,
}: {
  tokenAddress: string;
  contractAddress: string;
  requiredAmount: string;
  decimals: number;
}) {
  const { data: balance } = useERC20Balance({ token: tokenAddress });
  const { data: allowance } = useERC20Allowance({
    token: tokenAddress,
    spender: contractAddress,
  });

  const requiredWei = parseUnits(requiredAmount, decimals);
  const needsApproval = allowance === undefined || allowance < requiredWei;
  const hasSufficientBalance = balance !== undefined && balance >= requiredWei;

  return (
    <div>
      {!hasSufficientBalance && <div>Insufficient balance</div>}
      {hasSufficientBalance && needsApproval && <div>Approval required</div>}
      {hasSufficientBalance && !needsApproval && <div>Ready to proceed</div>}
    </div>
  );
}
```

## Complete Example: Token Swap Interface

Here's a complete example showing how to use multiple hooks together to create a token transfer interface with approval handling:

```tsx
import {
  useERC20Balance,
  useERC20Allowance,
  useERC20Approve,
  useERC20Transfer,
  useERC20Metadata,
} from '@radiustechsystems/sdk/react';
import { parseUnits, formatUnits } from 'viem';
import { useState } from 'react';

function TokenTransferWidget({
  tokenAddress,
  recipientAddress,
}: {
  tokenAddress: string;
  recipientAddress: string;
}) {
  const [amount, setAmount] = useState('');
  const [step, setStep] = useState<'input' | 'approving' | 'transferring'>('input');

  // Fetch token metadata
  const { name, symbol, decimals, isLoading: metadataLoading } = useERC20Metadata({
    token: tokenAddress,
  });

  // Check balance
  const { data: balance, refetch: refetchBalance } = useERC20Balance({
    token: tokenAddress,
  });

  // Check allowance
  const { data: allowance, refetch: refetchAllowance } = useERC20Allowance({
    token: tokenAddress,
    spender: recipientAddress,
  });

  // Approval hook
  const { approve, isPending: approvePending, isConfirmed: approveConfirmed } = useERC20Approve({
    token: tokenAddress,
  });

  // Transfer hook
  const { transfer, isPending: transferPending, isConfirmed: transferConfirmed } = useERC20Transfer({
    token: tokenAddress,
  });

  const decimalsNum = decimals ?? 18;
  const amountWei = parseUnits(amount || '0', decimalsNum);
  const hasAllowance = allowance !== undefined && allowance >= amountWei;
  const hasBalance = balance !== undefined && balance >= amountWei;

  const handleApproveAndTransfer = async () => {
    if (!hasAllowance && !approvePending) {
      setStep('approving');
      approve(recipientAddress, amountWei);
    } else if (hasAllowance && !transferPending) {
      setStep('transferring');
      transfer(recipientAddress, amountWei);
    }
  };

  if (metadataLoading) return <div>Loading token info...</div>;

  return (
    <div style={{ border: '1px solid #ccc', padding: '20px', borderRadius: '8px' }}>
      <h3>Transfer {symbol}</h3>

      <div>
        <label>Amount:</label>
        <input
          type="number"
          value={amount}
          onChange={(e) => setAmount(e.target.value)}
          placeholder="0.0"
          disabled={step !== 'input'}
        />
        <p>
          Balance: {balance ? formatUnits(balance, decimalsNum) : '0'} {symbol}
        </p>
      </div>

      <button
        onClick={handleApproveAndTransfer}
        disabled={!hasBalance || approvePending || transferPending || step === 'transferring'}
      >
        {step === 'approving' && approvePending && 'Approving...'}
        {step === 'approving' && approveConfirmed && 'Approval confirmed! Now transferring...'}
        {step === 'input' && !hasAllowance && 'Approve'}
        {step === 'input' && hasAllowance && 'Transfer'}
        {step === 'transferring' && 'Transferring...'}
        {transferConfirmed && 'Transfer complete!'}
      </button>

      {!hasBalance && <p style={{ color: 'red' }}>Insufficient balance</p>}
    </div>
  );
}
```

## Wagmi Integration

All Radius SDK hooks are built on top of wagmi v3 hooks and follow the same patterns. This means you can combine them with other wagmi hooks:

```tsx
import { useRadiusBalance, useRadiusContext } from '@radiustechsystems/sdk/react';
import { useAccount, useConnect, useDisconnect } from 'wagmi';

function WalletStatus() {
  const { chain } = useRadiusContext();
  const { address, isConnected } = useAccount();
  const { connect, connectors } = useConnect();
  const { disconnect } = useDisconnect();
  const { data: balance } = useRadiusBalance();

  if (!isConnected) {
    return (
      <button onClick={() => connect({ connector: connectors[0] })}>
        Connect Wallet
      </button>
    );
  }

  return (
    <div>
      <p>Connected to {chain.name}</p>
      <p>Address: {address}</p>
      <p>Balance: {balance?.formatted} {balance?.symbol}</p>
      <button onClick={() => disconnect()}>Disconnect</button>
    </div>
  );
}
```

## Error Handling

All hooks provide error states that you should handle:

```tsx
import { useRadiusBalance } from '@radiustechsystems/sdk/react';

function BalanceWithErrorHandling() {
```

## Best Practices

### 1. Always Wrap with RadiusProvider

```tsx
// Good
export function App() {
  return (
    <RadiusProvider>
      <YourComponent />
    </RadiusProvider>
  );
}

// Bad - hooks won't work outside provider
function BadComponent() {
  const balance = useRadiusBalance(); // Error!
}
```

### 2. Handle Loading and Error States

```tsx
function GoodComponent() {
  const { data, isLoading, isError } = useRadiusBalance();

  if (isLoading) return <LoadingSpinner />;
  if (isError) return <ErrorMessage />;
  return <BalanceDisplay data={data} />;
}
```

### 3. Use Type Safety

```tsx
// Good - define function parameters with types
function TransferWidget({ token, amount }: { token: Address; amount: string }) {
  const { transfer } = useERC20Transfer({ token });
  // ...
}

// Bad - no type safety
function TransferWidget(props: any) {
  // ...
}
```

### 4. Manage Approval Flow Properly

```tsx
function SmartTransfer() {
  const { data: allowance } = useERC20Allowance({
    token: tokenAddress,
    spender: contractAddress,
  });

  const { approve, isConfirmed: approveConfirmed } = useERC20Approve({
    token: tokenAddress,
  });

  const { transfer } = useERC20Transfer({ token: tokenAddress });

  const handleTransfer = () => {
    if (!allowance || allowance < amountNeeded) {
      approve(contractAddress, amountNeeded);
    } else {
      transfer(recipient, amountNeeded);
    }
  };
}
```

### 5. Use Custom QueryClient for Advanced Caching

```tsx
import { QueryClient } from '@tanstack/react-query';

const queryClient = new QueryClient({
  defaultOptions: {
    queries: {
      staleTime: 10 * 1000, // 10 seconds
      gcTime: 1000 * 60 * 5, // 5 minutes
    },
  },
});

export function App() {
  return (
    <RadiusProvider queryClient={queryClient}>
      <YourApp />
    </RadiusProvider>
  );
}
```

## Troubleshooting

### "useRadiusContext must be used within a RadiusProvider"

Make sure your component is wrapped with `RadiusProvider`:

```tsx
<RadiusProvider>
  <ComponentThatUsesRadiusHooks />
</RadiusProvider>
```

### Balance returns undefined

This usually means:
- The address parameter is undefined and no wallet is connected
- The data hasn't loaded yet (check `isLoading`)
- An error occurred (check `isError` and `error`)

```tsx
const { address } = useAccount();
const { data } = useRadiusBalance({
  address: address, // Make sure address is defined
});
```

### Transactions failing silently

Check the `error` property returned by transaction hooks:

```tsx
const { transfer, error } = useERC20Transfer({ token });

if (error) {
  console.error('Transfer failed:', error.message);
}
```

### Stale data being displayed

Manually refetch when needed:

```tsx
const { data, refetch } = useRadiusBalance();

// After balance changes
await refetch();
```
